# Glyphtender - Project Definition

**Created:** 2026-01-08
**Version:** 0.4.1

## Vision

Glyphtender is a hex-grid area control game with a spelling element - a strategic multiplayer experience where players compete to control territory through clever word formation and glyphling placement. The game prioritizes strategic depth over vocabulary size, making it accessible while rewarding tactical thinking.

**Meta-goal:** This app serves as a reference implementation and starting point for future game projects.

## Core Value Proposition

A polished online multiplayer word-strategy game that works seamlessly across networks with 2-4 players, featuring intuitive menus and smooth animations.

## Key Architecture Decisions

1. **Core/Unity Separation:** All game logic is pure C# in Core/, Unity layer handles rendering/input only
2. **Host-Authoritative Networking:** Host validates and broadcasts all game state changes
3. **3D UI System:** No Canvas - all UI is 3D objects in world space
4. **Unity Gaming Services:** Authentication, Lobby, and Relay for multiplayer infrastructure

## Success Criteria
