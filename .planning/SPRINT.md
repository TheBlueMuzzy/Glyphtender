- Deploying the online server to Cloudflare (PartyKit) + GitHub Pages is public → waits for you (/deliver).
- Turn timer default — built as **Off** (cozy, friends); the host can pick 60 / 90 / 120 s in the lobby. Change the list or the default in `content/rooms.json` → turnTimerChoices (the first is the default).
- A player who drops mid-game (timer off) — built: their seat waits **60 s**, then the simple sim player plays it until they come back (`botTakesOverAfterMs`). Longer? Or let the host choose "skip them"?
- Leaving mid-game — built: the seat is played by the sim player so the others can finish (they can come back by the code and take it back). Or should the game end for everyone?
- AFK — built: **2** missed turns in a row (turn timer on) → the sim player takes the seat (`missedTurnsBeforeBot`). Right number?
- Two players on one device in an online game — not built (Won't for alpha, as proposed).
- Play again online — built: the **host** starts the rematch (or New game → back to the lobby to change options); others see "Waiting for the host…". The design had a vote; OK as host-decides?
