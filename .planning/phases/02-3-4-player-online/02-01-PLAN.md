  <files>Unity/GlyphtenderUnity/Assets/Scripts/Unity/Network/GlyphtenderLobby.cs</files>
  <action>
  1. Remove `private const int MAX_PLAYERS = 2;`
  2. Add public property `public int TargetPlayerCount { get; private set; } = 2;`
  3. Update `CreateLobbyAsync()` to accept `int playerCount` parameter:
     - Set `TargetPlayerCount = playerCount`
     - Pass `playerCount` to `LobbyService.Instance.CreateLobbyAsync()`
     - Store player count in lobby data: `{ "playerCount", new DataObject(..., playerCount.ToString()) }`
  4. Update `IsFull` property to use `PlayerCount >= TargetPlayerCount`
  5. Add method `GetTargetPlayerCount()` that reads from lobby data (for guests to know target)
  6. In guest flow, after joining lobby, call `TargetPlayerCount = int.Parse(GetLobbyData("playerCount"))`

  Keep existing 2-player behavior as default for backward compatibility.
  </action>

  <done>GlyphtenderLobby accepts player count parameter, stores in lobby data, IsFull uses configurable count.</done>
